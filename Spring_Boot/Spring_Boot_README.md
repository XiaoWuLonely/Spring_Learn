# Spring Boot 学习

> ← 返回总览：[Java 学习训练仓库](../README.md)

通过独立模块学习 Spring Boot 应用的启动方式和 Web 接口开发。

## 学习路线

```
Sp001 → 配置 Spring Boot 应用入口，并编写第一个 REST 接口
```

|---|---|---|

## 公共技术栈

- Java 26
- Spring Boot 4.1.2
- Maven

## 如何运行

1. 用 IDEA 打开对应模块目录（Maven 项目会自动识别 `pom.xml`）
2. 等待依赖下载完成
3. 运行 `Sp001/src/main/java/oolong/heist/MyApplication.java` 中的 `main` 方法
